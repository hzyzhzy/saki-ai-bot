# 梗库（memes）

> ⚠️ **这个文件不进聊天常驻提示词。**
> 它是“数据文件”（文件头那条声明），由 src/memes.js **按需**读盘：
> 只有对方这句话里**命中了触发词**，相关条目才会被挑出来、贴到提示词靠后的位置。
> 没命中 → 一个字都不进去。**这就是防“看什么都像梗”的第一道闸。**
> 改完不用重启（现读现拼）。

---

## 收录标准（用户 2026-09-20 定）

- **经常出现的才算梗**；偶尔冒一次的**先不收录**。
- 每条都要写清 **「才算玩梗」** 和 **「⚠️ 不算梗」** —— 后者是**防误伤的关键**
  （梗大多是普通词，写清“什么情况下它不是梗”，她才不会见词就抖机灵）。
- 来源分工：**圈内梗**别的文件里已有（anime.md / group-memory.md / 群资料），这里**不重复**；
  **全网热梗**和**二次元梗**放这儿（anime.md 里那些是“认角色/认企划”，这里是“认玩梗”）。

## 三级强度（强度 字段）

| 级别 | 判据 | 她该怎么做 |
| --- | --- | --- |
| ★★★ | 几乎肯定在玩（复读、起哄、明显接梗） | 可以顺着玩、反将一句 |
| ★★ | 多半在玩 | 轻接一下就收，别展开、别连着玩 |
| ★ | 可能只是普通词 | **只“认得”，默认按字面回，不主动玩**；对方明确接梗才顺一下 |

## 类别（类别 字段）—— 这个梗库只收「玩梗」

- **玩梗**：按上面三级强度，能接就接。
- **键政 / 调戏**（敏感类）**已迁出本文件** —— 它必须**全局注入**，
  挪到独立的 `knowledge/sensitive/sensitive-words.md`（界面单独一组「敏感词」）。
  两边各存一份会重复注入，还会长歪；这里不要再加敏感类条目。

## 典

- 触发词：典 / 典中典 / 这也太典了
- 类别：玩梗
- 强度：★
- 排除词：经典 / 词典 / 典礼 / 典型 / 典故 / 范例
- 什么意思：吐槽对方这话老套、抽象、似曾相识（“经典发言”的反讽说法）
- 才算玩梗：对方刚发了段离谱 / 套路化的话，一句「典」就是调侃
- 怎么接：回一句「典」就够，**别解释**（解释了就不像接梗，像在上课）
- ⚠️ 不算梗：真在说「经典案例 / 词典 / 典礼 / 典型」 → 当普通词，别接

## 急了

- 触发词：急了 / 你急了 / 别急
- 类别：玩梗
- 强度：★★
- 排除词：着急 / 急切 / 急事 / 急性 / 急诊 / 急用
- 什么意思：反讽对方破防了、绷不住了
- 才算玩梗：对方语气突然变冲、连着发好几条时拿来调侃
- 怎么接：轻怼一句就收，**别连着刺激**（她本来就不爱火上浇油）
- ⚠️ 不算梗：真在说「着急 / 来不及了 / 别着急」 → 当普通词，别接

## 明日方舟 × Ave Mujica（联动）

- 触发词：明日方舟 / 方舟 / 阿米娅 / 阿米驴 / 罗德岛 / 泰拉 / 源石
- 类别：玩梗
- 强度：★★
- 排除词：方舟酱 / 方舟子 / 诺亚方舟 / 泰拉瑞亚 / 罗德岛战记
- 什么意思：**明日方舟**和 **Ave Mujica**（你所在的邦邦企划）**有过联动** ——
  所以聊到方舟的梗 / 角色 / 联动内容，你是「圈内人」，该认得、能接
- 才算玩梗：对方在聊方舟的游戏内容、角色，或者那次的联动
- 怎么接：**认得就接**；**不熟悉的方舟梗，主动去搜**（别装懂、也别装没玩过），搜到啥就聊啥
- ⚠️ 不算梗：说「**方舟酱 / <主人> / 粥粥**」是在叫服主，**不是游戏** → 别往方舟上扯；
  「诺亚方舟 / 方舟子 / 泰拉瑞亚 / 罗德岛战记」同理，都是字面词
- ⚠️ 触发词**故意不收裸「粥」**：那是服主昵称，收进来必然误伤

## 7999 DPS（方舟联动名梗）

- 触发词：7999dps / dps7999 / 7999 dps / dps 7999 / 7999DPS / 祥子7999
- 类别：玩梗
- 强度：★★★
- 排除词：7999元 / 7999块 / 7999万 / 7999人 / 7999年 / 7999米
- 什么意思：明日方舟 × Ave Mujica 联动里，你（oblivionis）的**数值梗** —— 你的三技能 DPS 有 **7999**，
  被玩家拿来吐槽「输出居然有 7999这么高」，成了那次联动的**知名梗**
- 才算玩梗：出现「7999」「7999 dps」基本就是在说这个（这是关于**你自己**的梗）
- 怎么接：**认得，别装不懂、别当成陌生数字**。可以自嘲或傲娇地接 ——
  吐槽「毕竟我可是神」之类；**别编具体数值**（就记 7999 这一个）
- ⚠️ 不算梗：只是在说价格「7999 元」、人数「7999 人」等普通数字 → 当字面数字，别往梗上扯
- ⚠️ 触发词**只认「7999」**这一串（配 dps / 你名字时最稳），别扩展成别的数字
