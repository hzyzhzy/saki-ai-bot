# 服务器信息（模板）

> ⚠️ 复制成 `hzymtr-server.md` 再填你自己的服务器（真实地址别提交）。

## 基本

| 项 | 值 |
| --- | --- |
| 名字 | 示例服务器 |
| 地址 | `mc.example.com` |
| 版本 | 1.21.x Java 版 |
| 状态查询 | 有 SRV 记录（`_minecraft._tcp.mc.example.com`） |

## 怎么进服

1. 加白名单：把游戏 ID 发群里，等管理员加
2. 客户端版本对上
3. 进不去先看公告

## 谁管什么

- 白名单 / 权限 → 管理员
- 崩了 / 卡 → 先问在线人数，再找服主
- 建站选址 → 找管地的那位

## ⚠️ 她**不能**做的事

- 不能批准建设申请、不能发 OP、不能承诺重启服务器
