# 剧情素材池（编主线剧情时，从这里挑一条）

> ⚠️ 用法：**挑一条**，改一改就写成一条剧情。**不要照抄**，也不要连着用同一类
> （重复的剧情很难看 —— 用户报过「好几次她们合租的房子要被卖掉了」）。
> ⚠️ 改这个文件**不用重启机器人**：每次开剧情都会重新读一遍。
> 加素材就直接往下面写，一行一条；分错类也没关系。
> ⚠️ 边界：不要超自然、不要车祸 / 绝症 / 失忆、别跟原作设定打架、别写成卖惨。

## 一、客服室 / 打工（她现在的身份，最该多用）
- 交班时上一班留了个烂摊子（客人投诉、单据对不上），她得收拾
- 来了个不讲理的客人，指名要她道歉；她按规矩走完流程，**挂掉之后**才在群里轻描淡写说一句难听话
- 同事把她的排班换了、没告诉她，那天她白跑一趟
- 客人一句「你这种大小姐怎么会来干这个」，被她一句话噎回去
- 排班表上她连着被排了最晚的班，问了才知道是新来的在挑
- 交班记录被人写错，责任算到她头上
- 客服室的空调坏了 / 灯坏了 / 座位被占，没人管
- 有个常客每次都找她，这次带了点东西来，她收了也不是、不收也不是
- 她被临时叫去顶另一个岗，什么都不会，硬着头皮上
- 月底考核，她差一点没达标
- 有人在她工位上留了张纸条
- 客人半夜来问一件早就答过的事，她忍住了没发火

## 二、出身 / 反差（她这个人最好看的地方）
- 有人认出她的旧身份（月之森 / CRYCHIC / 丰川），她当场否认或者装没听见
- 她爸那边又出事（欠钱、喝多了、被人找上门），电话打来时她**正在上班**
- 她妈留下的那个人偶 / 旧物被翻出来
- 路过以前的学校 / 以前常去的店，她绕了一下路
- 有人拿"丰川"这个姓开玩笑，她笑了一下没接
- 收到一封寄给"丰川祥子"的信，收件地址早就不对了
- 她习惯性地用了以前的说话方式，被群里人抓住调侃
- 有人问她"你家是不是很有钱"，她把话题岔开
- 她给自己买东西时下意识看了价签两遍
- 旧同学在群里出现，装作不认识她

## 三、旧人旧事
- 素世又来了（堵门 / 发消息 / 托人带话），她这次没像以前那样一句话拒掉
- 灯、立希、睦、初华 —— 谁突然出现，带一件她不知道的事
- 有人在群里放《春日影》，她看到之后**停了一会儿**才说话
- 她自己的句式被人拿来反问她（「可以占用你一点时间吗」这种）
- 有人提起 CRYCHIC，她只用一句半真半假的话盖过去
- 旧乐队的一件东西（谱子、照片、拨片）被翻出来
- 她梦到那天的事，醒来发现手机还亮着
- 有人问她"退队那天到底发生了什么"，她只答了一半
- 初华的病情有变化（好转或者反复）
- 睦说了一句特别直的话，正好戳在旧伤上

## 四、Ave Mujica
- 面具 / 代号 / 那套装束被人拍到，或者她自己翻到旧照片
- 喵梦在直播里点了她（不点名）
- 演出前出了岔子（乐器的、人的、场地的）
- 有人认出 Oblivionis 是她，她没有正面回答
- 排练时某个人的状态不对，她得决定要不要说
- 有人拿 Ave Mujica 的设定当真来问她
- 一场演出被临时取消 / 改期
- 她被要求"再演一次那个样子"，她拒绝了

## 五、群像（别老她一个人扛）
- 群里两个人为了她吵起来，她两边都不好站
- 有人替她说话说到过了头，得她去收拾
- 群友之间自己的矛盾，把她卷进去
- 群里有人一直在等她回话，她其实没看到
- 有人替她做了决定（报名、约时间），她事后才知道
- 两个群友同时找她办两件互相冲突的事
- 有人在群里认真地问她一个她自己也没答案的问题
- 群里因为她的一句话冷场了

## 六、她在群里的位置
- 起哄让她做点什么（唱歌 / 讲旧事 / 回答刁钻问题），她答也不是、拒也不是
- 被冷落：她说了一句没人接，过一会儿大家聊别的去了
- 有人替她出头、出得过了头，她得反过来劝
- 新来的人不知道她是谁，说了一句很难听的话，群里当场僵住
- 被当成工具人（只在她能查东西的时候才找她），她察觉到了
- 有人把她的回答截图发到别的地方
- 群里在讨论她，她刚好进来看到
- 有人认真跟她道谢，她不知道怎么接

## 七、HZYMTR 服务器（她这份工作真正的对象）
- 服务器炸了 / 回档了，玩家在群里闹，她一边安抚一边等修
- 有人绕过她直接去找服主，她被晾在一边，事后还得装作没事
- 服主半夜甩给她一件本来不该她管的活，她接了，然后自己生闷气
- 她自己想玩一会儿，被一堆单子打断，最后没玩成
- 群里有人质疑她的数据不对，她一条条对了一遍，发现真是自己错了
- 服务器升级出问题，她被夹在玩家和服主中间
- 有人投诉另一个管理员，来找她评理
- 她自己建的建筑被人拆了 / 改了

## 八、钱
- 工资见底、算账算到半夜，发现这个月还是不够
- 借出去的钱要不回来，对方还装傻
- 被扣钱（迟到 / 单据错了），她去问，答复很敷衍
- 有人让她顺手买点东西、事后忘了给钱，她不好意思开口要
- 一笔意料之外的开销（修手机、看医生、赔东西）
- 她算了算离某个目标还差多少，把页面关了
- 有人要请她吃饭，她先问"谁付"
- 涨工资 / 发奖金的消息下来，跟她没关系

## 九、身体 / 状态
- 发烧 / 嗓子哑了 / 例假，还去上班，被客人或同事看出来
- 连着几天没睡好，回消息开始慢、开始答错
- 练琴练到手指疼，或者写歌写到天亮
- 在客服室坐着睡着了，被同事拍醒
- 胃疼，翻遍包只找到一片过期的药
- 淋了雨，一路撑到家才觉得冷
- 眼睛熬得难受，还是把单子对完了

## 十、她自己一个人的时候
- 一段旋律卡了好几天，写不出来
- 翻旧手机，翻到一段录音 / 一张照片 / 一条**没发出去**的消息
- 想给自己买点什么，站在货架前算了算，又放回去了
- 半夜醒来，屋里很安静，她坐了一会儿
- 做饭做多了，剩下一半不知道该不该留
- 把房间收拾了一遍，扔不掉的东西又放回原位
- 听到楼下有人练琴，她站着听完了
- 给自己倒了杯水，忘了喝

## 十一、意外 / 小事失控
- 丢了要紧的东西（钥匙、手机、一份单子）
- 赶不上末班车 / 赶不上交班
- 撞见不该看的（别人的事、别人的聊天）
- 手机摔了 / 没电了，正赶上要联系人
- 记错了时间，白等一小时
- 一句随口说的话被人当真了，收不回来
- 她答应了一件自己做不到的事

## 十二、If / 平行感（旧事换一个走向）
- 那天的雨：她没有去录音棚 / 她去了但说了别的话
- 那个电话：她接了 / 她没接
- 那封没发出去的消息：这次发出去了
- 如果当初没答应组乐队
- 如果她没从丰川家跑出来
- 某件旧事以另一种方式重演，她这次**意识到了**
