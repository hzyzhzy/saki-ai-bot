# Saki 普通玩家客户端建造桥

适配 示例服务器：实例元数据为 Minecraft 1.20.1 / Forge 47.4.15。未在实例 mods 清单找到 JsMacros、KubeJS 或相应脚本运行时；这个客户端模组不依赖脚本引擎，也不要求服务器安装。

## 安装与首次验收

1. 关闭该游戏实例，手动把 `build/saki-client-1.20.1.jar` **复制**到 `C:/minecraftje/.minecraft/versions/示例服务器/mods/`。不要放到服务器。未替你安装或启动实例。
2. 从启动器选 示例服务器（游戏目录为上述版本目录），用游戏档案名 **Saki** 登录 `mc.example.com` 或 `mc.example.com:25565`。客户端自行创建游戏目录下 `saki-bridge/`。此目录应只对可信本机账户/主端开放，它不是带鉴权的远程 API。
3. 先发 `status`：只有匹配在线远程连接和玩家，才回 `done` 并包含 `player`、`position:{x,y,z}`、`dimension`。不要按服务器列表昵称或玩家皮肤名核对。
4. 用主世界生存模式站在施工点附近，快捷栏准备材料，关闭背包/菜单。先试一个有可见普通支撑的空气格，等待 `done`；再对已占位坐标请求，应回 `error` 并保持原方块。若不需桥，关闭游戏后移出该 jar 即可。

## 文件协议

主端使用唯一字符串 id，同目录写临时文件后原子替换 `inbox.json`。所有动作必须传 `expiresAt`（Unix 毫秒，创建时 `Date.now()+10000`）。接收时必须在期限内；正在执行的任务不受收件期限影响。示意：

```js
const req = {id: crypto.randomUUID(), server:'mc.example.com', action:'build', expiresAt:Date.now()+10000,
  blocks:[{x:100,y:65,z:100,block:'minecraft:glass'}]};
```

`stop`、`status` 无需 blocks。客户端用原子改名取走新件，使用原子替换写 `outbox.json`：`{id,status,message,...}`。单槽协议，不排队：主端等待同 id 回执才写下一单；施工时直接读 outbox 查看进度，仅用新 id 的 stop 中断。成功停止回 stop 请求的 id 和 `stopped`。同一进程忽略有效窗口内的重复 id；崩溃不会自动重放已领取文件，也不承诺跨重启恰好一次。停止不能撤回已发送的那次交互，不会拆已建部分。

## 动作界限

- 每单 1–256 个唯一整数坐标，最多 64 KiB；仅限主世界。材料：橡木木板、云杉木板、圆石、石砖、玻璃、红砖块、橡木原木、白色混凝土。按 Y 从低到高稳定排序。只用快捷栏中无 NBT 的匹配原版物品，选择材料会切换当前槽位。
- 只向**空气格**放一块；草、水、雪层和其他可替换方块也不动。支撑面只认八种建材及泥土、草方块、石头、深板岩、安山岩、闪长岩、花岗岩、基岩。中心射线必须首先命中对应支撑面，距离不超过实际原版触及范围且上限 4.5 格；仅检查已加载区块和世界边界内的位置。
- 不走路、不寻路、不挖、不发聊天或任意指令、不创物、不提权、不直接改世界。使用原版主手方块交互，取服务器确认后的客户端状态；其他模组/服务端插件仍可能取消或改变交互，不能承诺跨服务器锁定一个空位。
- 未确认、缺料、目标非空、支撑不可见、权限拒绝、切维度、死亡、掉线均终止，不重试，不回滚已放部分。主端应拆小区段，请玩家移动后另发新单。
- 性能：空闲每 5 个客户端 tick 仅查询收件文件是否存在，正常游戏约 4 次/秒，无新件不读 JSON；施工每步只查最多 9 个槽位、6 个邻面，无世界扫描、后台线程或网络探活。实例已有 Dynamic FPS 3.11.3，本桥不增加第二个帧率控制器，不改画质或 options.txt。未测试真实帧率、资源占用或线上放置。

## 离线编译和测试

在本目录用 JDK 17+ 执行 `java '-Dfile.encoding=UTF-8' Build.java`（PowerShell）。如依赖不在默认位置，追加本机 `.minecraft/libraries` 路径。使用实例自带的目标版本 SRG 客户端、Forge、Gson 等库；编译目标 Java 17，不联网，不复制游戏库。输出 `build/saki-client-1.20.1.jar`。构建先运行协议测试，覆盖动作、地址/端口、截止时间、白名单、数量、整数范围、重复坐标和底层顺序。Forge 运行时字段与访问转换器仅针对上述具体版本；测试不启动游戏，不代替安装后的在线验收。
